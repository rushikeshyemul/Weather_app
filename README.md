# 🌤️ Command Line Weather App

This is a simple command-line Node.js application that fetches and displays current weather information for any city using the OpenWeatherMap API.

## 🚀 Features

- Get real-time weather updates by entering any city name.
- Displays:
  - Temperature (°C)
  - Humidity
  - Weather Description
  - Wind Speed
  - Visibility
  - Cloudiness
  - Atmospheric Pressure
  - Sunrise Time
