# 🌤️ Command Line Weather App

This is a simple command-line Node.js application that fetches and displays current weather information for any city using the OpenWeatherMap API.

## 🚀 Features

- Get real-time weather updates by entering any city name.
- Displays:
  - Temperature (°C)
  - Humidity
  - Weather Description
  - Wind Speed
  - Visibility
  - Cloudiness
  - Atmospheric Pressure
  - Sunrise Time

---

## 🔑 Get Your API Key (Required)

To use this app, you'll need your own **OpenWeatherMap API key**:

1. Visit: [https://openweathermap.org/api](https://openweathermap.org/api)
2. Sign up or log in to your account.
3. Navigate to the **API Keys** section in your dashboard.
4. Copy your **API key**.
